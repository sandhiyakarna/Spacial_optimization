# FlowSpace Design System – Color Palette

Version: 1.0

---

# Purpose

This document defines the official color palette used throughout FlowSpace.

All frontend screens must follow these colors for consistency.

Do not introduce random colors unless specifically approved.

---

# Brand Identity

FlowSpace is an AI-powered interior planning platform.

The visual identity should communicate:

- Modern
- Premium
- Professional
- Minimal
- Architectural
- AI-driven

---

# Primary Brand Colors

| Name | Hex | Usage |
|------|------|------|

| Primary Dark | #115E59 | Hover states |
| Secondary | #5B5BD6 | AI features, highlights |

Do not introduce additional brand colors.

Dark mode and light mode must follow this document.

Any future UI components must comply with this design system.
